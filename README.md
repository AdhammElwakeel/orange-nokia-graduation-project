# Orange Nokia Graduation Project

## Run the dashboard

Install the required packages:

```bash
python3 -m pip install pandas streamlit
```

Keep the report at:

```text
~/Desktop/cell_sleep_distribution_report.csv
```

Then start the dashboard:

```bash
cd ~/Desktop/orange-nokia-graduation-project
streamlit run app.py
```

The dashboard shows energy savings, cell states, selected-time decisions, and load distribution from the report.
